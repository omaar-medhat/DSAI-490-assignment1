# Technical Report: Autoencoder and Variational Autoencoder for Medical MNIST

## 1. Introduction

This project implements and compares an Autoencoder and a Variational Autoencoder for medical image reconstruction, latent space visualization, sample generation, and denoising.

The Autoencoder learns a deterministic compressed representation of the input image. The Variational Autoencoder learns a probabilistic latent space, which allows new samples to be generated by sampling from a normal distribution.

## 2. Dataset

The Medical MNIST dataset was loaded from a `.zip` file stored in Google Drive or from a local path. Images were decoded as grayscale images, resized to 64 by 64 pixels, normalized to the range 0 to 1, and loaded using `tf.data`.

The dataset folders were used as class labels for latent space visualization.

## 3. Autoencoder Architecture

The Autoencoder contains a convolutional encoder and a convolutional transpose decoder. The encoder compresses each image into a latent vector. The decoder reconstructs the image from this latent vector.

The AE was trained using Mean Squared Error loss.

## 4. Variational Autoencoder Architecture

The VAE encoder outputs `z_mean` and `z_log_var`. A latent vector is sampled using the reparameterization trick:

`z = z_mean + exp(0.5 * z_log_var) * epsilon`

The VAE loss consists of reconstruction loss and KL divergence loss. The reconstruction loss measures output quality, while the KL divergence regularizes the latent space toward a standard normal distribution.

## 5. Experiments

The experiments included:

- AE reconstruction.
- VAE reconstruction.
- AE vs VAE visual comparison.
- MSE and SSIM quantitative comparison.
- 2D and 3D latent space visualization.
- VAE sample generation.
- Denoising Autoencoder training and evaluation.

## 6. Results and Observations

The Autoencoder usually produced sharper reconstructions because it directly optimizes reconstruction error. The VAE produced smoother reconstructions because it balances reconstruction quality with KL divergence regularization.

The VAE was able to generate new samples by sampling from the latent space. This is a key advantage of VAE over AE.

The denoising Autoencoder improved noisy images by learning to map corrupted inputs back to clean targets.

## 7. Conclusion

The AE is better suited for direct reconstruction, while the VAE is better suited for generative modeling and latent space exploration. The denoising experiment showed that autoencoder models can also be applied to image restoration tasks.
